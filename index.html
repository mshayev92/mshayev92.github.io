Daily Briefing

Python · 2026 · runs every morning

A personal pipeline that reads my coursework, email, calendar and campus events each morning and turns them into one prioritized page I read on my phone.

  • A systemd timer at 6:30 AM runs the whole chain: refresh Canvas, collect from Gmail, Drive and Calendar, rank items, render the page, back it up to Drive.
  • A "What changed" section built from the scraper's change log, so I see new grades and deadlines rather than the same list every day.
  • Every LLM call is logged with its cost and runs under a per-run budget. Logging showed that extended thinking made up ~95% of the spend, so I turned it off by default.
  • FastAPI serves the page over Tailscale. State lives in SQLite. 14 test files check the code against the written spec.

Canvas Scraper

Python · Playwright · 2026

A read-only scraper for UMD's Canvas that works without an official API token. Every professor organizes Canvas differently, so it discovers each course's structure rather than assuming one.

  • Logs in through UMD SSO and Duo push with encrypted stored credentials, then keeps a headed browser session alive on a server with no display (Xvfb).
  • An incremental-sync cache stores snapshots of every assignment, page and announcement, so downstream tools can ask "what's new since yesterday?"
  • A canvas CLI answers cross-course questions, plus trigger-driven automations ("when a new chapter appears, summarize it").
  • Documents what the instance actually exposes, endpoint by endpoint, and what it does not reliably expose.

NJWG Encampment App

JavaScript · PWA · Cloudflare Workers · 2026

An installable staff app for the Civil Air Patrol New Jersey Wing summer encampment: schedule, roster, inspections, observations, announcements and push notifications, backed by a Google Sheet that staff already knew how to edit.

  • The site is public, so no page is a security boundary. A Cloudflare Worker enforces everything server-side.
  • Two layers of signed tokens: a passphrase unlocks a device (short-lived on shared desk devices), then a per-position session decides which pages load.
  • Rate limiting, a read cache in front of the Sheets API, Web Push, and an offline fallback for spots with bad signal.
  • 142 commits over the summer, including a full backend migration from Google Apps Script to the Worker.

Pension Allocator Intelligence

Internship · Nine Advanced Technologies · 2026

A business-development database built from public DOL Form 5500 pension filings. It shows which plans already work with the firm's partners and which are worth contacting.

  • Structures 9,021 plan allocators and 1,718 leads from Schedule C and Schedule D filings into one queryable schema.
  • Matches adviser and fund names across filings with tiered fuzzy matching, and ranks 318 firms for further enrichment.
  • Ships as a single static page over a JSON dataset: search, filters and an outreach pipeline, with no server to maintain.
  • The public demo uses synthetic placeholder data. Every firm, person and contact in it is generated.
